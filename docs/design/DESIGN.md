# DESIGN.md — Nila Design System

The **moonlight** system. The feeling is moonlight on a pale wall: calm, quiet,
reflective — soft luminance, never glare. Cool near-white surfaces, a deep
midnight-sea "ink", a hushed sea-blue primary warmed by a single sand accent,
soft layered shadows, and an editorial serif over a light sans. No purple.

> The *why* behind these choices — the moon, calm, soft luminance — lives in
> [`BRAND.md`](BRAND.md). Read it first; this file is how that brand is built.

This is the authoritative reference for UI work in Nila. It complements
`AGENTS.md` (Elixir/Phoenix rules). When building or restyling UI, follow this.

## Stack

- **Tailwind v4** (no `tailwind.config.js`) — tokens live in `assets/css/app.css`.
- **daisyUI v5** — single light theme defined in `app.css`. Components inherit it.
- **HEEx / Phoenix LiveView 1.1** — markup in `lib/nila_web`.

There is **no dark mode** — light only.

## Color

Defined as the daisyUI `light` theme in `assets/css/app.css`. Use semantic
daisyUI/Tailwind tokens (`primary`, `base-content`, `base-300`…) in markup —
never hard-code hex.

| Token | Value | Role |
| --- | --- | --- |
| `primary` | sea blue `#316177` → `oklch(47% 0.06 232)` | Primary actions, links, accents |
| `accent` | warm sand `#d3c0aa` → `oklch(80% 0.035 78)` | The lone warm note — the amber window. Use sparingly. |
| `base-100` | white | Page & card background |
| `base-200` | cool near-white | Subtle section fills |
| `base-300` | cool light gray | Borders, hairlines |
| `base-content` | midnight ink `#004865` → `oklch(30% 0.055 233)` | Primary text |
| `success` / `warning` / `error` | green / honey-amber / red | Status |

The palette is teal-blue, **no purple** — night over water. Chroma is kept low
on purpose; calm reads as desaturated. The warm sand is the one deliberate
warmth held inside the cool — reserve it for a genuine accent, never decoration.
Let ink and whitespace carry the page.

Body text on white uses `base-content`; secondary text uses
`text-base-content/70`, muted labels `text-base-content/60`.

## Type

- **DM Sans** is the body/UI sans (loaded in `root.html.heex`, registered as
  `--font-sans` in `app.css`). Body is antialiased.
- **Newsreader** is the display face for hero and large headings — an editorial
  serif (Google Fonts). Registered as `--font-display`; apply with the
  `font-display` utility (auto-generated by Tailwind v4). The serif's
  contemplative, reflective tone is deliberate — see `BRAND.md`.
- **Weight is the signature.** Lean light:
  - Display / hero headings: `font-display font-normal` (400) + `tracking-tight`
    + tight `leading-[1.05]`. The serif reads best lighter; scale with size, not
    weight. Italic is available for emphasis.
  - Sub-section headings (inside cards): DM Sans `font-semibold tracking-tight`.
  - Body / supporting copy: `font-light`.
  - Labels, table data, badges, buttons: `font-medium` / `font-semibold`.
- **Eyebrows**: small uppercase kickers — `text-eyebrow font-semibold uppercase`,
  often via `.text-moon`. The `text-eyebrow` token bakes the 0.2em tracking; never
  hand-write `tracking-[0.2em]`. For UI micro-labels use `text-label`.
- Numbers use `tabular-nums`.

**Name the role, never the pixel.** Size, line-height, and tracking live in the
`text-{role}` scale (`text-hero`…`text-micro`, `text-eyebrow`, `text-label`) —
see [`docs/design/TYPOGRAPHY.md`](docs/design/TYPOGRAPHY.md). Don't reach for raw
Tailwind sizes (`text-sm`, `text-xs`, `text-2xl`, …) or arbitrary
`text-[13px]`/`tracking-[…]`/`leading-[…]`; the scale already bundles the trio, so
pairing a manual `leading-`/`tracking-` with a role doubles up. `mix
nila.style_guard` enforces this across `lib/nila_web`.

## Radius & borders

Set in the theme: fields/buttons `0.5rem`, cards (`rounded-box`) `0.875rem`,
borders `1px`. Use `rounded-box` for cards and `rounded-field` for small chips.
Borders are 1px `base-300` hairlines — quiet, never heavy.

## Signature utilities

Defined in `assets/css/app.css`. **Reuse these — do not invent one-off
gradients or shadows.** The look comes from restraint.

| Class | Use |
| --- | --- |
| `.moonlight` | The hero ground: a pale cool wash with a soft pool of light up top, fading to near-white. Pair with **ink** text, not white. |
| `.moonlight-soft` | An even quieter wash for section backgrounds. |
| `.text-moon` | Low-chroma sea-blue clipped to text — eyebrows, figures, accents. It whispers. |
| `.shadow-moon` | Soft layered elevation in the night-ink hue. Default card shadow. |
| `.shadow-moon-lg` | Heavier lift for floating/primary surfaces. |

## Patterns

- **Cards**: `rounded-box border border-base-300 bg-base-100 p-5 shadow-moon`.
  They lift gently off the page; the border keeps edges crisp.
- **Hero**: a `.moonlight` ground with **ink** (`text-base-content`) headline and
  copy — light text on light. Let content cards below overlap it with a negative
  top margin (`-mt-28`) for depth.
- **Primary button**: daisyUI `btn btn-primary` (sea blue) + `shadow-moon`.
- **Sticky header**: translucent `bg-base-100/80 backdrop-blur` with a 1px
  bottom border.
- **Status**: `badge badge-primary badge-soft` for soft pills.

## Don't

- Don't hard-code hex colors in markup — use theme tokens.
- Don't use raw Tailwind sizes (`text-sm`/`text-xs`/`text-2xl`/…) or arbitrary
  `text-[Npx]`/`tracking-[…]`/`leading-[…]` — name a role from the type scale
  ([`docs/design/TYPOGRAPHY.md`](docs/design/TYPOGRAPHY.md)). `mix
  nila.style_guard` fails the build on raw sizes.
- Don't pair a `leading-*`/`tracking-*` with a `text-{role}` — the role bundles
  both (exceptions: `leading-none`/`tabular-nums` on figures).
- Don't reach for heavy headings (`font-bold` on display type) — stay light.
- Don't add bespoke gradients/shadows — use the utilities above.
- Don't add a dark theme or `tailwind.config.js`.
