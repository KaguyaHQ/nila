# BRAND.md — Nila

The *why* behind the product. This is brand essence and voice — the reasoning
that the visual system in `DESIGN.md` exists to express. Read this first; it
changes rarely.

## The name

**Nila** (நிலா) — the moon.

The moon is cyclical, calm, reliable, quiet. It doesn't demand attention — it's
just there, every night, doing the thing. It works while you sleep. It's
reflective, not generative — it doesn't produce its own light, it processes and
softens what's already there. In Tamil and the broader Indian cultural register,
*nila* carries grace, soft luminance, and contemplative calm — the opposite of
solar hustle.

## Essence

This is not a coincidence with the product. Nila is back-office automation:
work that happens quietly, in the background, on a dependable cycle — processing
what arrives and surfacing only what needs a human. The brand should feel like
the moon, not the sun.

| Trait | Means |
| --- | --- |
| **Calm** | Never loud, urgent, or attention-seeking. Confidence, not hype. |
| **Reliable** | Cyclical and dependable. It just works, every night. |
| **Quiet** | Recedes until needed. The work is the point, not the tool. |
| **Reflective** | Processes and softens what's already there; doesn't invent. |
| **Graceful** | Soft luminance over hard glare. Restraint as a feature. |

## Voice

- Plain, precise, unhurried. State things; don't sell them.
- No exclamation marks, no "supercharge / blazing-fast / revolutionary."
- Respect the reader's time and intelligence — they're professionals (CAs, SMB
  operators), not leads to convert.
- Confident understatement: "Documents arrive, workers process them, humans
  approve exceptions." Let the calm do the work.

## How this shows up in the product

The brand traits are the source of the design decisions in `DESIGN.md`:

- **Calm / graceful → muted, low-glare palette.** Lean on the navy "ink" and
  whitespace; reserve saturated color for genuine accent, never decoration.
- **Quiet → restraint.** Few type sizes, few weights, soft 1px borders, gentle
  shadows. The UI recedes; the data leads.
- **Reflective → soft luminance, not hard contrast.** Soft layered shadows and
  light type weights over heavy bold and harsh edges.
- **Reliable → consistency.** Reuse the same tokens, utilities, and patterns
  everywhere; surprise is not a virtue in a back office.

The visual system in `DESIGN.md` is built to express this — a hushed, low-chroma
**moonlight** palette: cool near-white grounds and a deep midnight-sea ink,
warmed by a single sand accent (the one amber window in a blue night). Teal-blue,
no purple — night over water. Soft luminance over glare. Lunar, not solar.
